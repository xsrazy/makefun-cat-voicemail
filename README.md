Entry for the [Funniest Cat Voicemail Greeting](https://make.fun/bounty/u-eager-stork-81-9647-funniest-cat-voicemail-greeting-8eaad443) bounty on make.fun.

## The greeting

> Hi, this is Beans. I pushed your phone off the counter and now I'm napping on it. Leave a message after the beep.

113 characters, inside the 120 character limit.

## How it works

`main.py` writes the greeting to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). It
validates the text first: non-empty and at most 120 characters.

## Why this line

Ten candidates were written and judged head-to-head against the
bounty brief. This one won because it reads as a real voicemail
(greeting, name, "leave a message after the beep"), it stacks two
behaviours only a cat would do (pushing a phone off a counter, then
napping on it), the cat speaks in the first person with a clear
attitude, and the punch lands before the beep line, so it works
spoken aloud in a few seconds.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
